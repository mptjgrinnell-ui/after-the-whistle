# After the Whistle

Course project site for CIS 300 (Web Design and Development) at ASU, built by Matthew Johanson.

The site is about what happens to athletes once their competitive playing career is over, and the
real options for staying in it at the recreational level, coaching, and officiating.

Live site: https://mptjgrinnell-ui.github.io/after-the-whistle/

## Files

- `index.html` - the home page
- `afterthewhistle.css` - the external style sheet
- `images/federer-hero.jpg` - header photo
